### উদাহরণ (কোন উদাহরণ দ্রুত পূরণ করলে):
- ফিচার নাম: সাপ্লায়ার থেকে পে-রোল ডিডাকশন ইমপোর্ট
- মডিউল: Accounting / Payroll
- সংক্ষেপ: ব্যাচ CSV আপলোড করে ডিডাকশন যোগ করা যাবে।
- User Story: As an HR, I want to upload deduction CSV so that payroll runs include deductions.
- Acceptance Criteria:
  - CSV ফাইল আপলোড করা গেলে সার্ভারে ভ্যালিডেশন হবে, ভুল সারি রিপোর্ট হবে।
  - সফল হলে DB তে ডিডাকশন রেকর্ড তৈরি হবে এবং একটি সারাংশ/downloadable report তৈরি হবে।
- API: `POST /api/v1/payroll/deductions/import` (multipart/form-data)
- Permissions: HR Manager, Admin
- Estimated effort: 8-13 hours
